# Tekey マルチキャラパレット

Tekey で複数の PC を一人で動かすときに使う、ブラウザだけで動くチャットパレットです。
バフ・デバフや固定値はアプリ側で管理して計算し、Tekey には `2d+20 命中力` のように計算が済んだコマンドだけを送ります。
そのため、Tekey 側のパレットで `//01命中修正=0` のような変数を管理する必要がなくなります。

## 使い方

1. `index.html` をブラウザで開きます（ビルドやサーバーは不要です）。
2. キャラクターを用意します。「取込 / 保存」から次のどれかを選びます。
   - **ゆとシートII から取込**: キャラシートの URL を入力します。ブラウザの制限で取得できないときは、「JSON 出力」を開いて中身を貼り付けてください。
   - **Tekey のパレット JSON を読込**: Tekey から書き出したパレット JSON を読み込みます。パレットの `name` ごとに 1 キャラとして分けられ、`01` や `02` などの番号の接頭辞は取り除かれます。
   - **空のキャラを追加**
3. 上のタブで PC を切り替えます。右側の「バフ・デバフ」で修正値を ± ボタンか数値入力で変えると、パレットの計算結果がすぐに更新されます。
4. パレットの行をクリックすると入力欄に入ります。Enter で送信します。▶ を押すと、その場ですぐ送信します。

## 送信方法（⚙ 設定）

| 方法 | 内容 |
|---|---|
| コピー（既定） | 送信内容をクリップボードにコピーします。Tekey のチャット欄に貼り付けて送ってください。 |
| Tekey API | `https://tekey.jp/api` に `sendChat` を送ります。API キー・ルーム ID・ルームパスワードが必要です。 |

- 名前と色は、既定ではメッセージの末尾に `@[name]:キャラ名@#色` を付けて指定します。設定で API の name / color パラメータを使う方法にも切り替えられます。
- API のパラメータ名は「設定 → 詳細」で変えられます。初期値は仮のものなので、[Tekey API のヘルプ](https://helps.tekey.jp/api-about/) の表記に合わせてください。
- 既定では、応答を読まない `no-cors` で送信します。届いたかどうかは Tekey の画面で確認してください。
- API での送信に失敗したときは、クリップボードへのコピーに自動で切り替えます（設定でオフにできます）。

## パレットの書き方

Tekey のパレットとほぼ同じ書き方です。

```
■戦闘                                   ← ■ で始まる行は見出し
2d+{命中1}+{命中修正} 命中力／{武器1}      ← {変数} は固定値・バフデバフから展開
k{威力1}[({C値1}+{C修正})]+{追加D1}+{追加D修正}$+{クリレイ} ダメージ
x2 2d+{命中1} 命中力／両手利き
「カッコイイ戦闘前口上」                   ← コマンドでない行はそのままチャットとして送信
```

- 固定値は「キャラ設定・固定値」タブで `名前=値` の形式で書きます。値には `{他の変数}` や四則演算を使えます。割り算の端数は切り捨てます。
- コマンド部分は、`+18+0+2` を `+20` にまとめるなど、計算できるところを計算してから送ります。
- 未定義の変数がある行には「未定義」と表示されます。

## 保存

- データはブラウザの localStorage に自動で保存されます。
- 「アプリデータを書き出し」で、すべてのキャラクターを JSON ファイルに保存できます。別のブラウザや別の PC へ移すときに使ってください。API キーとパスワードはこのファイルに含まれません。

## ファイル構成

- `index.html`: 画面
- `style.css`: 見た目
- `engine.js`: 変数の展開とコマンドの計算
- `importers.js`: Tekey パレット JSON とゆとシートII の取り込み
- `app.js`: 画面の操作・保存・送信
