    名前と文字色

    API 送信では name / color パラメータで、コピー送信ではメッセージ末尾の @[name]:名前@#色 で指定します。

    Tekey 側の処理が重くなるため、使わない場合はオフのままにしてください。

    Tekey API

    API キーは Tekey への問い合わせで発行してもらえます。API キーなどはこのブラウザの localStorage にだけ保存され、アプリデータの書き出しには含まれません。送信回数の上限は 1 分に 60 回、1 日に 5,000 回です。

    詳細（API パラメータ名・通信方式）

    初期値は Tekey API ヘルプ（2026/10/31 時点）の仕様どおりです。通常は変更不要です。空欄の項目は送信しません。

    応答を読まない場合（既定）は no-cors で送信します。届いたかどうかは Tekey の画面で確認してください。
